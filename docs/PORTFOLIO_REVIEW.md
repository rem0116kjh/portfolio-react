## 검사와 한계

- npm ci 성공.
- npm run lint 성공.
- npm run build 성공 (수정 후 최종 결과는 커밋 직전 재확인).
- 별도 typecheck 스크립트 없음. TypeScript 전환을 임의 도입하지 않음.
- 브라우저에서 기존 GitHub 탭의 저장소와 시작 커밋 확인.
- sites-preview가 http://terminal.local:4173/ 제공. 연결된 Chrome은 해당 주소를 net::ERR_BLOCKED_BY_CLIENT로 차단. 차단을 우회하지 않음.
- 따라서 데스크톱·모바일 렌더링, 실제 클릭→상세→뒤로 가기, 테마 유지, 키보드 탐색, 외부 링크 대상 응답, 대비·가로 넘침은 브라우저 실검증 미완료. 소스 반응형/접근성 구현을 실제 검증 통과로 보고하지 않음.
- font subset 재생성은 Python Brotli 부재로 실행 실패. 기존 unicode-range subset과 원본 fallback을 재사용하므로 누락 글자는 원본 폰트로 표시하도록 유지.
- 이 작업은 포트폴리오 구현 검증이며 ReadIn/GHAS/MapOn 앱의 재검증 결과가 아님.
