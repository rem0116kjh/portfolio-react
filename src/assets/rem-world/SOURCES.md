# Rem World design assets

Adapted from the reference supplied by the portfolio owner on 2026-10-21:
https://rem0116kjh.github.io/design-archive/%ED%94%BC%EC%B9%98%EC%9B%94%EB%93%9C/index.html

- `astronaut.svg`, `laptop.svg`, `space-bg.jpg`: illustrations and background from the reference's `assets/` directory.
- `barlow-900.ttf`: Barlow Black display font distributed with the reference. Barlow is licensed under the SIL Open Font License; see `BARLOW-OFL.txt`.
- `pretendard.woff2`: Pretendard variable font distributed with the reference. Pretendard is licensed under the SIL Open Font License; see `PRETENDARD-OFL.txt`.
- `portfolio-sans.woff2`, `fonts.css`: generated by `scripts/subset-fonts.py` from the original variable font and current portfolio text. The derived font is internally renamed Rem Portfolio Sans under the original SIL Open Font License. Weight variations and glyph outlines are retained; characters outside the subset still load the unchanged original font through CSS unicode ranges.
- `barlow-900.woff2`: lossless WOFF2 encoding of the original Barlow font, retaining its character coverage and SIL Open Font License.

Project illustrations are CSS compositions based on that reference and existing project descriptions. They are labeled as illustrations. The GHAS image uses the existing App Store screenshot documented in `../projects/SOURCES.md`.
